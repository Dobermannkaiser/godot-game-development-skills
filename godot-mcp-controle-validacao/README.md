# Godot MCP — Controle, Segurança e Validação

Skill derivada do benchmark de 27 testes realizado no Golem’s Mandate em agosto de 2026.

## Conteúdo

- `SKILL.md` — regras operacionais, autorização, validação e roteamento.
- `references/benchmark-27-testes.md` — relatório técnico completo que sustenta as regras.

## Uso recomendado

Use esta skill junto de uma skill de programação Godot. Ela deve ser ativada sempre que houver:

- Godot MCP;
- Codex editando projeto Godot;
- criação/alteração de cenas via MCP;
- execução e debug automatizados;
- investigação/correção de bugs;
- mudanças de save/load;
- alterações em production code.

A regra mais importante é simples: **inspecionar primeiro e pedir autorização explícita antes de qualquer alteração.**
